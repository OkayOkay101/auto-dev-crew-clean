## หมายเหตุ
- เขียนหน้าภาษาอังกฤษก่อน แล้วจึงเขียนหน้าภาษาไทยคู่กันที่มีหัวข้อและลิงก์เหมือนกัน ถ้าสองภาษาไม่ตรงกัน ให้ยึดโค้ดเป็นหลัก
- [README_TH.md](../README_TH.md) คือหน้าแรกภาษาไทย ส่วน [CONTRIBUTING.md](../CONTRIBUTING.md) (ภาษาอังกฤษ) สำหรับผู้ที่แก้ไขโค้ด
- [../REQUIREMENTS.md](../REQUIREMENTS.md) เป็น **ร่างข้อกำหนด v0.2 (2026-10-30)** เขียนตอนออกแบบครั้งแรก ตอนนี้ระบบใช้ **Antigravity CLI (`agy`)** เป็นหลัก ไม่ได้รันบน GitHub Actions แบบที่ร่างไว้ และ F6 ทำแล้วบางส่วน อ่านเป็นประวัติการออกแบบได้ แต่ไม่ใช่สเปกปัจจุบัน
- โฟลเดอร์ `docs/superpowers/` มี spec และ plan ของงานแต่ละชิ้น ใช้อ้างอิงประวัติการตัดสินใจ

## แหล่งความจริงของเอกสารนี้
หน้าต่าง ๆ ถูกตรวจกับโค้ดในรีโปเมื่อวันที่ 2026-11-18 ยังไม่มีการอ่านทวนทีละประโยคโดยเจ้าของภาษาอังกฤษ ถ้าโค้ดเปลี่ยนแล้วเอกสารไม่ตาม ให้ยึดโค้ดเป็นหลัก แล้วแก้เอกสาร
