# Simple Mode + บทแนะนำการใช้งาน (Tutorial) — Design

Date: 2026-11-16 · Size: small change · Status: implemented (awaiting user review)

## Intent
ผู้ใช้ใหม่ควรเห็นหน้าควบคุมที่เรียบง่ายก่อน และมีบทแนะนำสั้น ๆ พาไปรู้จักเมนูหลัก
Users who open the control panel for the first time should see a simple layout first, with a short guide to the main panels.

## Goals
- ครั้งแรกที่เปิดหน้าควบคุม ใช้โหมด "ง่าย" (Simple) เป็นค่าเริ่มต้น
- ซ่อนบล็อกขั้นสูงในโหมดง่าย ผู้ใช้สลับเป็น "โปร" ได้ที่มุมบนขวาเสมอ
- เปิดบทแนะนำอัตโนมัติครั้งแรก และเปิดซ้ำได้จาก ตั้งค่า › บทแนะนำการใช้งาน

## Non-goals
- ไม่เปลี่ยน nav (ยังมี 5 หน้าเดิม) และไม่แก้ backend / gui.py
- ไม่ commit (ยังไม่ได้รับคำสั่ง)

## Anti-goals
- ห้ามทำให้ผู้ใช้เดิมที่เคยเลือก "โปร" ไว้ถูกเปลี่ยนกลับเป็นง่ายโดยไม่รู้ตัว

## Approaches
1. **(เลือก)** ใช้สวิตช์ ง่าย/โปร ที่มีอยู่แล้ว (`data-ui-mode`) เพิ่มกติกาซ่อน `[data-pro-only]` และเปลี่ยนค่าเริ่มต้น — เปลี่ยนน้อย ทดสอบง่าย
2. สร้างหน้าแยกสำหรับโหมดง่าย — ซ้ำซ้อนกับหน้าเดิม ดูแลยาก (ไม่เลือก)

## Design
- **ค่าเริ่มต้น:** ถ้ายังไม่มี `adc_ui_mode` ใน localStorage → `simple`. สคริปต์เล็กใน `<head>` ตั้ง attribute ก่อนวาดหน้า กันเมนูขั้นสูงวาบ
- **การโหลดหน้า** ไม่เขียน `adc_ui_mode` ทับ (เดิมเขียน `pro` ทุกครั้ง) ค่าที่ผู้ใช้กดเองเท่านั้นที่ถูกบันทึก
- **ซ่อนในโหมดง่าย (ติด `data-pro-only`):** การ์ด "การตรวจก่อน merge", "เครื่องมือระบบ", "หาปัญหาในโค้ด (AI-TODO / สแกนลึก)", "ลำดับสำรอง (failover)", แท็บ "การใช้งานล่าสุด"
- **บทแนะนำ:** 6 ขั้น (ต้อนรับ, ภาพรวม, สตูดิโอ, คีย์ AI, งาน, ตั้งค่า) TH/EN ตาม `adc_lang` ใช้ textContent เท่านั้น ข้ามได้ทุกขั้น; ขั้นที่มีหน้าเป้าหมายจะพาไปหน้านั้น
- **จำการดูแล:** `adc_tutorial_done = "true"` เมื่อเสร็จหรือข้าม. ถ้า storage ใช้ไม่ได้ บทแนะนำจะเปิดทุกครั้งที่โหลด

## Left to the builder (my calls)
- ชุดการ์ดที่ซ่อนในโหมดง่ายคือการตัดสินใจของผม แก้ได้ด้วยการเพิ่ม/ลบ `data-pro-only`
- ผู้ใช้เดิมที่ไม่เคยดูบทแนะนำจะเห็นบทแนะนำหนึ่งครั้ง แต่โหมดที่เคยเลือกไว้ยังคงเดิม
