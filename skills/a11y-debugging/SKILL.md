# Accessibility (a11y) Debugging

## Principles
1. Every input widget must have an explicit label or `aria-label`.
2. Do not rely exclusively on color to convey error or success states.
3. Ensure high contrast ratio (minimum 4.5:1 for normal text).
4. Maintain logical keyboard Tab order across all form controls and action buttons.
